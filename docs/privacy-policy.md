# プライバシーポリシー — Send to Cursor for GitHub

日本語 | [English](privacy-policy.en.md)

最終更新日: 2026-08-20

Send to Cursor for GitHub（以下「本拡張」）は、GitHub の PR と Issue に、その内容を渡すプロンプト付きで Cursor の新しいチャットを開くボタンを追加する Chrome 拡張です。本拡張の開発者はサーバーを運用しておらず、利用者のデータを受け取りません。

## 保存する情報

本拡張が保存するのは、設定ページで利用者が指定した設定だけです。

- 表示言語
- リンクの開き方（`cursor://` を直接開くか、`https://cursor.com/link/` を経由するか）
- ボタンのラベルと、ラベルを表示するかどうか
- 対象ごとにボタンを出すかどうか
- 対象ごと・言語ごとのプロンプトのテンプレート（既定値から編集した場合のみ）

保存先は Chrome の `chrome.storage.sync` です。Chrome にログインして同期を有効にしている場合、これらの設定は Google のアカウントを通じて利用者自身の他の端末にも同期されます。その同期は Chrome の機能であり、Google のプライバシーポリシーに従います。開発者はこの内容を参照できません。

閲覧履歴、Cookie、認証情報、個人を識別する情報は取得しません。解析ツールや広告は組み込んでいません。

## ページから読み取る情報

本拡張は `https://github.com/*` のページでのみ動作し、ボタンを押したときに渡すプロンプトを組み立てるため、開いている PR / Issue のページから次の内容を読み取ります。

- リポジトリ名、PR / Issue の番号・タイトル・URL
- head / base のブランチ名、Issue のラベル
- 説明文やコメントの本文（Markdown 原文）、投稿者名、コメントの URL、レビューコメントの対象ファイル名と行番号
- 失敗した CI チェックの名前・URL・状態と、表示されている annotation

いずれも、そのページを開いている利用者にすでに表示されている情報を、ページの DOM から読み取っているだけです。本拡張から GitHub の API を呼ぶことはありません（本文の Markdown 原文を得るために、GitHub 自身のメニュー読み込みを促す操作だけを行います）。

読み取った内容はプロンプトを組み立てるためだけに使い、本拡張が保存することはありません。開発者へ送信することもありません。

## 外部への送信

読み取った内容は、利用者が選んだ「リンクの開き方」によって次のように扱われます。

- `cursor://` を直接開く場合（既定）: プロンプトは URL として端末内の Cursor アプリに渡されます。ネットワークへの送信は発生しません。
- `https://cursor.com/link/` を経由する場合: プロンプトは URL の一部として cursor.com（Anysphere Inc.）に送信され、そこから Cursor アプリに渡されます。この場合、プロンプトに含まれる PR / Issue の内容も同時に送信されます。非公開リポジトリの内容が含まれることがあるため、この設定を選ぶかどうかは利用者の判断に委ねられています。cursor.com での取り扱いは Cursor のプライバシーポリシーに従います。

いずれの場合も、開発者のサーバーを経由することはありません（開発者はサーバーを持っていません）。

Shift + クリックでプロンプトをクリップボードにコピーする操作でも、送信は発生しません。

## 第三者への提供

本拡張が扱う情報を、販売・貸与・第三者への提供のいずれも行いません。

## Chrome Web Store の Limited Use について

本拡張は Chrome Web Store のユーザーデータポリシー（Limited Use の要件を含む）に準拠します。本拡張が扱う情報は、上記の単一の目的（GitHub の PR / Issue の内容を渡して Cursor のチャットを開くこと）に必要な範囲に限られ、他の目的には使いません。人による読み取りは行わず、販売もしません。

## 設定の削除

保存した設定は、Chrome から本拡張を削除すると一緒に削除されます。同期を有効にしている場合は、他の端末の設定も同期に従って削除されます。個別に消したい場合は、設定ページで「すべてのプロンプトを既定値に戻す」を実行するか、`chrome://extensions` から本拡張を削除してください。

## 変更

本ポリシーを変更する場合は、このファイルを更新し、変更日を最終更新日として記載します。データの取り扱いを変える変更の場合は、拡張の更新に合わせてストアの説明文にも記載します。
